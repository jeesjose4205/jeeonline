# Personal portfolio

## Start locally

1. Run `npm install`
2. Run `npm run dev`
3. Open http://localhost:3000

## Personalise

Edit `src/app/page.tsx` for your profile, links, projects, skills, and contact address. Replace `public/resume.pdf` with a real PDF before deployment.

## Deploy

Push to GitHub and import the repository in Vercel. The standard Next.js defaults work without additional configuration.
